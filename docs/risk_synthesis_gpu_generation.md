# 设备端几何生成优化

本文记录v12的GPU优化及当时系数0.1的局部计时。后续v13已删除额外噪声系数，当前生成与基准脚本使用 \(L\epsilon\)；下文历史测试和计时仍属于v12，不能转作v13测量结果。协议变更见 [当前方法](risk_synthesis_method.md)。

2026-09-15。本次优化仅改变 `risk_synthesis` direct 模式的生成计算位置及因子缓存；全部数值有效方向、风险中心、噪声幅度、标签、多视图平均损失与一次原始 batch 一次 optimizer 更新保持原定义。

原流程将高维原始 token 从 GPU 传到 CPU，在 CPU 执行 `latent @ factor.T`，然后将每个视图传回 GPU。当前流程让原始 token、中心混合、噪声矩阵乘法和生成结果保留在输入设备。CUDA 下，固定全局类别因子和均值在首次使用时传到 GPU，后续视图与客户端共享缓存。CPU 环境继续走 CPU 计算路径，历史筛选生成路径保持原实现。

缓存是运行级 LRU，驻留上限为首次使用时空闲显存四分之一与 2 GiB 中的较小值；超过上限时淘汰最久未使用的条目，单个超大条目只临时传输，不保留在缓存中。这个上限只约束缓存驻留量，不是整个训练显存的上限；模型、激活与当前生成工作区仍需要显存。缓存关闭时释放，不写入共享统计产物。

低维标准高斯向量继续使用原来的客户端 CPU Generator，保持视图、类别、记录抽样顺序，仅将低维向量传到 GPU。相同输入与种子下 CPU/GPU 随机数状态一致，但不同设备的矩阵运算不保证逐位一致；后续训练和风险轨迹仍可能因浮点差异发生变化。摘要以 `generation_compute`、`generation_rng`、`generation_device_cache` 记录执行方式、缓存预算与命中/淘汰计数。

## 验证与局部计时

真实 CUDA 测试覆盖全部方向（有效秩大于5）、全局/本地中心、零秩类别、连续多视图抽样、客户端之间的缓存复用、输入和生成 token 留在 GPU、CLS 保留与优化后计数。另验证 LRU 字节限制、淘汰、超大条目和清理行为。相关 direct/global 测试共41项通过，包括 Adapter/LoRA 的 CPU 小模型训练与11种攻击集成；CUDA生成测试为真实设备测试。

后续兼容性回归覆盖旧部分/全部替换、历史风险、范数协议、多视图与统一入口：193项通过，沙箱内跳过的3项CUDA测试已在上述真实CUDA测试中全部通过。

在 RTX 4090 上，用合成因子测试 `d=37632`、rank=99、batch=32、views=2，每条记录对应一个类别，固定同一批次交替测试10次：

| 测量项 | 结果 |
|---|---:|
| CPU生成及高维来回传输，中位数 | 58.62 ms |
| GPU生成，缓存已加载，中位数 | 4.81 ms |
| 局部生成耗时比 | 12.19 倍 |
| GPU首次加载缓存及生成 | 334.27 ms |
| 两设备候选最大绝对误差 | 2.38e-7 |
| 测试缓存驻留量 | 481,689,600 bytes |

原始计时：[benchmark.json](../analysis_scripts/synthesis_gpu_generation_20260915/benchmark.json)。该测试不使用真实图片统计，不包含输入编码、风险计算、模型前后向、攻击审计或CSV记录；缓存命中条件固定，两张GPU当时均有其他任务，单次GPU耗时存在波动。不能将12.19倍解释为完整训练加速倍数，也不能据此判断新防御的任务效用与隐私效果。
