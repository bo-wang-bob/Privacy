# 简化历史暴露与多候选选择：验证协议

2026-09-13。用户要求验证最新方案是否有效，并尽可能减少超参数。本次将后续诊断提出的两个组件接入正式 `risk_synthesis`，采用明确、固定的简化规则。训练效果必须由新的百轮实验判断，现有原因关联和固定教师探针不作为新防御有效性结果。

## 简化后的方法

对原始样本 i，定义截至上一参与轮的历史量：

`E_i = mean_over_observed_rounds(mean_over_visits_in_round(used_risk_i == 0))`。

零风险访问仍使用 `h + 0.1 L epsilon`，不是原图回退。这个因子突出原编码系数为 1 的访问；它不描述全部信息泄漏，也不统计数据依赖协方差与其他供体中心的间接影响。首轮真实发生的零风险访问也计入历史；所有记录同样访问时不会改变下一轮相对排序。缺失历史记零，记录可用历史轮数。

历史均值代替 EMA，去掉衰减率 beta；已有风险权重中精确定义的零风险事件代替保留量幂次，去掉 p 及额外近原样阈值；两个信号采用固定等权秩合并，去掉可调 lambda。固定等权仍是一个设计假设，不能因为不开放配置就声称没有方法选择。

本轮对原始损失差 M 与历史 E 分别计算带并列中秩的排名，取秩之和排序。和相同时按 M，再按原 batch 顺序稳定排序。使用整数秩计数相加后归一化，避免非 2 的幂长度短 batch 的浮点误差破坏并列规则。将原 WWW 尾部权重的同一数值集合重新分配给新排序；不改变 batch 平均保留量、普通 CE、优化步数或聚合权重。历史整轮冻结，只有 optimizer 成功后才累计本批 used-risk；重复 epoch 对每个原始记录先取轮内平均。

多候选复用既有 `attempts=2`，本次两次都评价，每个原始位置仍只用一个候选训练。在语义合格者中，选择与**全部客户端本地原始样本**最大教师余弦相似度最低的候选；相似度并列时优先语义 margin 更高者，再优先较早候选。包含源样本、其他供体及其他类别，避免只降低源身份优势却奖励接近另一个私有供体。所有候选都未达语义门槛时，仍按用户要求保留语义最佳的有效虚拟候选。有效性检查失败、无法形成改变后的有限编码时在优化前报错。

新增可调数值超参数为 0。选择规则不新增隐私距离阈值或语义—隐私加权系数，也不另设候选数。`risk_history` 与 `candidate_selection` 是用于组件消融的离散协议开关。**方法仍保留原有几何、噪声和语义参数，不能称为整个方法无超参数。** 两候选上限复用不代表计算量不变：旧规则合格后提前结束，新选择必须评价两次，需实测额外开销。

| 参数或规则 | 本次处理 | 原因 |
| --- | --- | --- |
| EMA beta、保留幂次 p、可调融合 lambda | 移除 | 使用历史频率和固定对称排名 |
| 新候选数量 K | 不新增 | 复用现有 attempts=2，每位置选择一个 |
| 新隐私距离阈值、目标混合权重 | 不新增 | 语义约束优先，其后比较最近原始样本相似度 |
| 全替换比例 1、warmup 0、uniform 中心 | 固定协议约束 | 保持用户要求，不作为搜索参数 |
| class_rank=5、pooled_rank=16、shrinkage=0.5、noise_scale=0.1 | 维持原值 | 本轮隔离历史与候选选择，未做参数搜索 |
| margin_tolerance=0.02、norm_ratio=[0.1,2]、min_class_samples=3 | 维持原值 | 延续语义与生成有效性约束 |
| WWW 高风险尾部比例 0.8 | 维持原值 | 保持风险值集合完全匹配 |

## 冻结实验

统一入口、CLIP transformer Adapter、CIFAR100、FedAvg 100轮、每轮一个完整本地 epoch、10个 IID 客户端、全局每类100张、batch32、lr0.01、sample_count 聚合。全部11种攻击保持既有频次；审计目标客户端0的1000个原始成员与1000个独立 evaluation 非成员。候选身份不因虚拟编码或重复 epoch 扩大。

- seed43：复用已核验的无防御、原全替换、原打乱风险结果，新运行仅 E、仅候选选择、组合、组合分数整体打乱四组。
- seed44、45：各复用已完成且协议匹配的无防御结果，新运行原全替换、预先指定的组合及组合整体打乱三组。
- 合计10个新百轮任务、5个已有对照。不通过 seed43 选出表现最好的组件后替换预定组合。所有轮数固定100，不选中途最佳 checkpoint。
- 这些种子及来源清单此前已研究；多种子复验不等同于全新未接触数据确认，不推导跨模型结论。

每个种子相对无防御检查既有整体标准：11攻击最大 AUC 至少下降0.02、最大 TPR@1%FPR下降、准确率损失不超过2个百分点。组合相对原全替换的新增价值单独报告：如要称三种子方向一致，须每个种子最大 AUC 和最大 TPR均下降、准确率损失均不超过2个百分点。组合相对整体打乱也单独判断，不能把整体生成收益归给历史排序。逐攻击、类内指标、语义失败率、历史暴露分布、实际时间均报告；条件于固定模型的候选重采样区间不能替代种子间变异。

原始 `results/` 不覆盖。计划记录训练源码及复用结果指纹；每个新任务仍由统一入口创建独立一级目录。逐批流式日志额外保存本地损失差、冻结 E、联合排序、打乱前后的风险；选择组保存两个候选的本地教师指标，独立验证器重放整个选择决策与历史更新。日志仅供本地研究核验，统计、编码和历史不共享，无 DP 保证。
