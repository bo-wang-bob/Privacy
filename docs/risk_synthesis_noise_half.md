# 噪声幅度0.5的五轮对照

用户在v13五轮检查后要求尝试0.5噪声。本次保持相同的风险规则、数据身份、模型、视图数和训练预算，只将噪声改为：

\[
\tilde h=(1-r)h+r\mu+0.5U\sqrt{\Lambda}\epsilon.
\]

固定几何时，相对v13噪声幅度为一半、期望能量为四分之一；相对旧0.1系数，幅度为5倍、能量为25倍。仍使用特征值平方根，不采用论文的特征值本身。

## 实验设置

- Adapter与LoRA，CIFAR100、seed43、10个IID客户端、全局每类100张训练数据。
- FedAvg5轮、每轮1个完整本地epoch、batch32、学习率0.01、按样本数聚合。
- 每条原始记录2个视图，全部数值有效方向，全局均值包含自身。
- 每轮评估；关闭成员攻击，仅判断早期效用和训练稳定性。
- 默认GPU0串行运行两项；每次执行创建新任务，不覆盖或续写历史结果。

运行：

```bash
cd /root/Privacy
/root/.local/share/mamba/envs/pfedba/bin/python scripts/run_synthesis_noise_half.py
```

追加 `--dry-run` 只检查配置。该脚本继续调用既有全局验证入口及唯一批量调度器，没有独立训练实现。

## 版本和兼容性

默认catalog及direct配置仍不含 `noise_scale`，继续使用v13的 \(L\epsilon\)。按本次要求，显式提供有限正数 `defense.synthesis.noise_scale` 时启用 `local_token_geometry_v14_direct_scaled_noise`，摘要记录幅度及 `noise_scale_parameter_enabled=true`。本试验脚本固定该选项为0.5。零、负数、非有限值、布尔值和null被拒绝。

v12带系数与v13无系数的历史结果继续按记录版本核验，不改写。v14恢复幅度选项不恢复候选筛选、重试或教师。模型、风险、视图平均、GPU缓存和成功后统计清理继续使用既有实现。

实现验证：242项CPU/协议回归通过，另有5项真实CUDA测试通过；覆盖无参数与显式幅度、CPU/CUDA抽样一致性、双模型1/2/3视图、全部11种攻击及统计清理。上述软件测试不代替真实数据效果实验。

## 评价口径

优先与刚才v13五轮任务同轮比较，核对完整解析配置和 `data_partition.json`；旧0.1与无防御的第5轮结果作为补充参照，其评估频次为每5轮一次。报告准确率、评估损失、原始访问/视图数、参数和指标有限性及耗时。本次没有AUC或TPR结果，不能宣称隐私收益。清理后的统计分析仅使用保留凭据，不重算已删除协方差。

## 实际结果（2026-09-16完成）

批次 `20260915_235353_727870` 的两项均成功，总耗时约9分27秒。两模型相对刚才单位幅度任务，完整解析配置仅有显式幅度和输出目录差异，训练/evaluation身份一致。

| 模型 | 1.0第5轮 | 0.5第5轮 | 相对1.0 | 旧0.1第5轮 |
|---|---:|---:|---:|---:|
| Adapter | 63.98% | 72.18% | +8.20个百分点 | 77.45% |
| LoRA | 65.67% | 67.22% | +1.55个百分点 | 68.91% |

0.5改善了相对单位幅度的早期效用，仍低于旧0.1的同轮结果。Adapter的0.5曲线为73.04%、72.38%、71.15%、71.28%、72.18%，后两轮恢复；LoRA为65.76%、66.49%、66.93%、67.12%、67.22%，五轮持续上升。每项1600个batch、5万次原始访问、10万个视图通过核验，参数和指标有限。该五轮单种子结果不代表最终收敛或隐私收益。
