8. 先建立 Adapter/CIFAR100 的证据，再验证 LoRA 和 Food101 的适用范围。任何结论必须写明模型、数据、客户端划分、攻击与训练预算；不从一个成功配置推出普适保证。

## 输入期望的推导及其限制

这是对本方案的代数分析，不是防御效果或差分隐私证明。条件是固定同类 n 个样本的风险 r，忽略每批请求上限与语义筛选，噪声独立且零均值，替换概率 p_i。记 q_i=p_i r_i。使用排除自身的类别均值时，一个本地 epoch 的输入编码和满足：

\[
\mathbb E\left[\sum_i h_i^{\mathrm{train}}\right]
=\sum_j w_j h_j,
\quad w_j=1-q_j+\frac{1}{n-1}\sum_{i\ne j}q_i
=1+\frac{\sum_i q_i-nq_j}{n-1}.
\]

所以 Σ_j w_j=n，较高 q 的记录被降低权重，而其他同类记录获得补偿。若 p_i=ρr_i，则 q_i=ρr_i²；若同类所有风险相同，w_j 全为 1，类别输入编码和的期望完全不变。生成数量本身不表示类别聚合信息已减少。

在“输入直接进入线性分类层，且同类各样本损失对 logits 的导数近似相同”的额外近似下，上传梯度也近似表现为这种加权。当前 CLIP 后续 Transformer 非线性、FedAvg 多步和语义筛选均会破坏该梯度近似，因此不能直接据此预测实际攻击 AUC。

这给出两条待结果验证的方向：一是加入匹配的原图风险降权对照，识别几何生成的额外价值；二是检查高风险记录的筛选回退率，如果高风险候选大多被拒绝，实际 q 会远小于请求机制暗示的强度。第一轮试验暂不因此更改参数，避免跳过原方案的测量。

还有一个与子空间攻击直接相关的性质：均值移动是原始编码的仿射组合，经验类内协方差的低秩方向也来自原始编码的中心化线性组合。因此当前全部虚拟输入仍位于该客户端原始输入编码的仿射包内，加入本地合并类内协方差也不会改变这一点。这个性质可以通过投影残差数值验证。

它意味着不能声称现有几何噪声必然破坏输入层的子空间线索。当前 ProjRes 观察的是后续非线性 Transformer 的表示，其攻击表现仍须实际测量。如果真实实验发现子空间类攻击持续有效，可以在相同框架内检验额外的、与私有经验子空间无关的小幅噪声先验，并继续用固定教师约束语义；这一扩展尚未实现，也不自动给出 DP 保证。

## 随机项幅度与实际生成中心的补充诊断

从已保存的 1,000 个客户端类别几何计算，类内秩 5 因子保留原方差的中位数为 74.30%（范围 64.24%–93.01%），客户端类内共享秩 16 因子约保留 30.73%–32.45%。在当前 b=0.1、收缩系数 0.5 下，筛选前随机项的均方根范数相对于完整原始类内波动，范围为 6.50%–9.31%，中位数 7.34%。计算使用 tr(b²LLᵀ)/tr(C_c) 的平方根，并对客户端 0、类别 0 从原始编码直接重算完整协方差迹，确认恢复公式相符。证据位于 `analysis_scripts/risk_synthesis_noise_energy_20260912/`。

这只描述未筛选的零均值随机项，不包含中心移动，也不是已接受样本的方差；筛选会引入条件相关。它支持保留零噪声消融，区分小幅随机项和均值移动的作用，不能将其直接解释为防御强弱。

另外，对目标客户端 0 的全部访问，令 A_i 为已接受替换的风险权重之和，v_i 为访问次数。实际输入中去除随机项后，中心和可精确写为 Σ_j w_j h_j，其中同类 n=10 时：

w_j = v_j - A_j + (Σ_{i:y_i=y_j} A_i - A_j)/(n-1)。

每类的 Σ_j w_j 等于原访问总数，已逐类核对。五个固定初始风险组的平均系数依次为 10.0370、9.9758、9.9619、9.9992、9.9894；无防御每条记录为 10。最高组虽然平均只有 9.6731 次直接原图训练，却仍经其他样本的同类均值重新进入生成中心。产物位于 `analysis_scripts/risk_synthesis_realized_centers_20260912/`。

这个分解只适用于生成中心，排除了随机项；非线性 Transformer 的梯度和训练后模型并不由这些总系数唯一决定。它不能充当因果归因或隐私保证，但说明“减少某记录的直接训练次数”不等于“减少它经本地统计进入训练的全部贡献”。

## 下一项有界改进：风险进入排除自身的类别中心

已实现可选 `defense.synthesis.center_weighting=previous_risk`，默认仍为 `uniform`。改动来自两个已验证现象：当前风险排序在实际接受预算相同的短程对照中没有收益；减少一条记录的直接训练，仍可能通过其他样本的同类均值把它重新引入。

新方式保留原始本地协方差、噪声、请求概率、每批上限和固定教师筛选，仅改生成中心。记录 j 的中心权重为 `a_j=1-mean(used_risk_j)`，均值来自该客户端上一参与轮的全部有效风险访问；重复 epoch 求平均，缺少历史时用 1。使用：

\[
\mu_{c,-i}^{a}=\frac{\sum_{j:y_j=c,j\ne i}a_jh_j}{\sum_{j:y_j=c,j\ne i}a_j},
\qquad \tilde h_i=(1-r_i)h_i+r_i\mu_{c,-i}^{a}+bL_c\epsilon.
\]

权重在当前客户端整轮内冻结，不随当前 batch 访问顺序变化。正常全参与时，第 1 轮为原图训练；第 2 轮沿用均匀中心；第 3 轮开始使用第 2 轮分配的风险。这里中心风险比当前替换请求滞后一参与轮，不是把过去的权重伪称为当前风险。打乱风险对照把其 assigned/used-risk 同样用于后续中心，避免保留未打乱风险的隐藏信息；与选择单个 donor 的 MixUp 不兼容，入口会拒绝该组合。极端情况下所有同类 donor 权重为零则回退均匀中心并记录；当前尾部中点秩小于 1，不会通常触发此回退。

在固定风险/中心权重、无筛选和无 batch 上限的单 epoch 期望下，令 `q_i=p_i*r_i`、`A=sum(a)`，原始编码 j 的中心系数为：

\[
w_j=1-q_j+a_j\sum_{i\ne j}\frac{q_i}{A-a_i},\qquad \sum_jw_j=n.
\]

因此可以同时降低直接路径和经其他中心进入的份额。固定风险的基向量测试验证了该系数与实际生成中心的期望一致，以及高风险记录的再引入份额下降。这不是当前非线性模型、多步优化、滞后风险和筛选机制下的隐私证明；协方差依旧由全部原始记录拟合，虚拟编码仍处于私有经验仿射包内。

新增 `anchor_reference_round`、`anchor_available_donors`、`anchor_source_weight`、`anchor_donor_weight_sum`、`anchor_uniform_fallback` 流式字段；分析器从已记录的历史 used-risk 用独立 NumPy 累积重放，核验权重及来源。小模型测试覆盖冻结历史、不同客户端隔离、重复访问平均、跳过参与轮、缺少风险、打乱风险对应、排除自身及错误诊断拒绝。均匀权重和零权重回退保留旧生成算术及随机序列；Adapter/LoRA 在 SGD momentum 与 AdamW 下，三轮、每轮两本地 epoch 的零替换对照与普通 FedAvg 所有最终参数逐位相同。29 项生成测试和 CLIP 协议/结构回归合计 **95 项通过**。

```bash
/root/.local/share/mamba/envs/pfedba/bin/python scripts/run_privacy_experiments.py \
  --models clip_adapter --datasets cifar100 --methods fedavg \
  --defenses none,www,risk_synthesis --attacks all
```

同一生成器的风险消融使用 `--set defense.synthesis.mode=shuffled_risk`，所有位置仍替换。历史同类 MixUp、零噪声和风险加权中心仅在显式 `replacement_policy=risk_probability` 模式中支持，不能直接套用到新全部替换默认值。

每次干运行核对最终协议后再运行。新实验保存在新的 `results/` 一级任务目录中，历史结果不修改。

复现已在上述 Adapter/CIFAR100 确认范围内通过验收的历史部分替换、范数下限 0.1 方案：

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
/root/.local/share/mamba/envs/pfedba/bin/python scripts/run_privacy_experiments.py \
  --models clip_adapter --datasets cifar100 --methods fedavg \
  --defenses risk_synthesis --attacks all --seeds 42 \
  --set defense.synthesis.replacement_policy=risk_probability \
  --set defense.synthesis.replacement_fraction=0.25 \
  --set defense.synthesis.warmup_rounds=1 \
  --set defense.synthesis.norm_ratio_min=0.1
```

此命令使用常规默认数据分区、默认 100 轮与默认 FedAvg 审计频次，不复现预留源记录确认分区。确认分区的命令补充与简明结果见[结果说明](risk_synthesis_results.md)。10 轮探索的每两轮全攻击覆盖见对应队列中保存的实际命令；不能直接将不同轮数/频次的结果配对。
